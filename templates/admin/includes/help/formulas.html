Fórmulas

Una fórmula puede combinar números, operadores y referencias a otros conceptos de la liquidación. También puede escribirse en varias líneas.

Usá un punto para separar los decimales, por ejemplo 10.23.

Si dejás el cursor sobre una unidad, se muestra su descripción.

Operadores disponibles

  • + suma
  • - resta
  • * multiplicación
  • / división
  • ** potencia
  • () paréntesis

Referenciar conceptos y bases imponibles

Cada detalle y cada base imponible tiene un identificador visible que podés usar en una fórmula. Por ejemplo, para tomar el 11 % de sueldo_basico_17: 

sueldo_basico_17 * 0.11

La referencia toma el valor de Importe del detalle.
